# Ghita Labs V1

Static bilingual website (English/French), designed to be hosted for free.

## Before publishing
1. Contact email configured: `ghitalabs@gmail.com`.
2. If you later add a custom domain, add canonical and hreflang URLs.
3. Optional: create a dedicated OpenGraph image (1200×630) from the logo.
4. Test the final public URL on mobile and desktop.

## Free hosting
This folder can be deployed as-is to GitHub Pages or Cloudflare Pages. No build step is required.

## Structure
- `index.html`: site content and semantic structure
- `styles.css`: responsive visual system
- `script.js`: language switcher + lightweight interactions
- `404.html`: custom error page
- `robots.txt`: search crawler rules
- `ghita-labs-logo.png`: Ghita Labs logo at repository root for easy iPhone/GitHub upload

## Product states
- EXP.001 Startly — PAUSED
- EXP.002 LedgerFold — RESEARCH

No analytics, accounts, database, cookies, API keys or backend are included in V1.
